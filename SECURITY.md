# Security Policy

## Reporting a vulnerability in WebRecon

If you find a security issue **in WebRecon itself** (not in a site you scanned),
please report it privately rather than opening a public issue:

- Open a [GitHub Security Advisory](../../security/advisories/new), or
- Email the maintainer (see the repository profile).

Please include: a description, steps to reproduce, affected version, and impact.
We aim to acknowledge reports within a few days and to fix confirmed issues
promptly. Please give us reasonable time to release a fix before public
disclosure.

## Responsible use

WebRecon performs active security testing (crawling, injection probes, optional
brute-force, rate-limit bursts). Use it **only** against systems you own or are
explicitly authorized in writing to test. Unauthorized use may be illegal. The
tool asks you to confirm authorization before every scan for this reason.

## Supported versions

The latest released version on the default branch is supported. Older versions
are not maintained.
