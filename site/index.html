Everything in one tool

From reconnaissance to reporting to continuous monitoring — a full vulnerability-management workflow that runs entirely on your machine.

🛡️

26+ OWASP checks

SQLi, XSS, SSTI, SSRF, XXE, IDOR, CSRF, CORS, JWT, NoSQLi, CRLF, GraphQL, secrets-in-JS, and more — each with a copy-paste proof.

🎯

Exploit intelligence

Matches detected versions to CVEs, ranked by EPSS + CISA KEV, and flags when a public Exploit-DB / Metasploit exploit exists.

📡

Blind-vuln confirmation

Built-in OAST listener confirms blind SSRF and RCE out-of-band — turns "maybe" into "confirmed".

🔁

History & diff

Every scan is saved to a local database. See exactly what's new or fixed since your last scan.

🔔

Continuous monitoring

Watch a target on a schedule and get alerted (Slack / Discord / webhook / email) the moment a new issue appears.

🧩

Extensible

Add detections with drop-in YAML templates — Nuclei-style, no code. Bring your own CVE DB and wordlists.

⚡

Rate-limit advisor

Detects missing rate limiting and recommends the right algorithm per endpoint (sliding window, token bucket, leaky bucket).

📄

Pro reports

Color-coded console, styled HTML, JSON, and SARIF for GitHub code-scanning and CI pipelines.

🔐

Safety-first

Authorization gate on every scan. Intrusive checks (brute-force) are opt-in with attempt caps and lockout awareness.

Get started in seconds

Two ways to run it — a one-file Windows download, or install from source.

EASIEST · WINDOWS

Download the .exe

No Python required. Download, open a terminal in that folder, and run:

webrecon.exe scan http://example.com --authorize
⬇ Download webrecon.exe
Seeing "Windows protected your PC" / "isn't commonly downloaded"? That's Microsoft SmartScreen warning about any new, unsigned open-source app until it earns download reputation — not a sign the file is unsafe. Click More info → Run anyway. For peace of mind, verify the SHA-256 against webrecon.exe.sha256 on the release page, or use the source install on the right (no .exe, no warning).
RECOMMENDED · ANY OS · NO WARNING

Install with pip

The cleanest way — no download prompt, works everywhere:

pip install webrecon-scanner webrecon scan http://example.com --authorize

On Windows you can also use Scoop (no warning):

scoop install https://github.com/DanishDhanjal15/CYBER-TOOL/releases/latest/download/webrecon.json
